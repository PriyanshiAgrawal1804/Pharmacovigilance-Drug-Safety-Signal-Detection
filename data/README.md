# Data Directory

## ⚠️ Data status: synthetic

`raw/synthetic_faers_sample.csv` is **simulated data**, not real FAERS
extracts. It is generated by [`R/00_generate_synthetic_data.R`](../R/00_generate_synthetic_data.R)
and structured to mirror a real FAERS case-report table so the pipeline can
be built, run, and demonstrated end-to-end.

Real FAERS data is public and free, and is the intended production input for
this pipeline:
- Quarterly extracts: https://fis.fda.gov/extensions/FPD-QDE-FAERS/FPD-QDE-FAERS.html
- Live query API: https://api.fda.gov/drug/event.json

Swapping in real data means pointing `R/01_data_preprocessing.R` at a real
extract with the same `drug` / `event` / `time_to_onset_days` columns — no
changes needed downstream.

## Files

| File | Description |
|---|---|
| `raw/synthetic_faers_sample.csv` | 50,000 simulated case reports: `case_id`, `drug`, `event`, `sex`, `age_band`, `country`, `report_date`, `time_to_onset_days`, `serious` |
| `raw/ground_truth_signals.csv` | The drug-event pairs deliberately seeded with an elevated reporting rate in the simulation, used to validate that the pipeline recovers known signals |
| `processed/case_level_clean.csv` | Cleaned/de-duplicated case-level data (output of step 01) |
| `processed/drug_event_matrix.csv` | Drug × Event contingency table, N_ij counts (output of step 01) |
| `processed/disproportionality_results.csv` | PRR / ROR / chi-square per pair (output of step 02) |
| `processed/ebgm_results.csv` | EBGM / EB05 / EB95 empirical Bayes scores per pair (output of step 03) |
| `processed/time_to_onset_results.csv` | Weibull shape parameter test results (output of step 04) |

`processed/` is regenerated by `run_pipeline.R` and is not tracked in git
(see `.gitignore`) — run the pipeline to produce it locally.

## Column notes: `synthetic_faers_sample.csv`

| Column | Type | Notes |
|---|---|---|
| `case_id` | string | Synthetic unique case identifier |
| `drug` | string | Active ingredient (15 simulated drugs) |
| `event` | string | Adverse event term (16 simulated MedDRA-style terms) |
| `sex` | F / M | |
| `age_band` | string | 5 age bands |
| `country` | string | Reporting country code |
| `report_date` | date | 2020-01-01 to 2025-12-31 |
| `time_to_onset_days` | integer | Days between drug start and event onset; seeded true signals follow an early-clustering Weibull(shape≈0.7), background pairs follow Weibull(shape≈1.4) |
| `serious` | Y / N | |
